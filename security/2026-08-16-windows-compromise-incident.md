## 主要入侵迹象

### 远程控制迹象

最直观的异常是鼠标被非本人控制，并试图打开微信。这类现象通常需要高度重视，因为它可能意味着远控木马、远程管理工具滥用、会话劫持或其他后门组件正在活动。

### 安全防护被篡改

排查过程中发现 Microsoft Defender 曾处于异常关闭状态，实时防护、杀毒服务等能力一度不可用。

同时，Defender 曾被加入大量危险排除项，覆盖系统盘、用户目录、Program Files、ProgramData 及若干恶意落点目录。这类排除项会显著降低杀毒软件发现恶意文件的能力，是典型的防护规避手段。

还发现一个异常的 Code Integrity / WDAC 策略文件，创建时间与可疑入侵时间吻合。该策略曾阻断 Defender 关键组件运行，隔离后 Defender 恢复正常。

### 持久化痕迹

发现并清理了多处持久化项，包括：

- 计划任务：伪装成 Edge 更新任务或业务/系统名称的任务。
- HKLM Run 启动项：伪装成 Tencent / Alibaba 安全健康类名称。
- 异常服务：服务指向一个位于 Windows Temp 下、扩展名伪装为 `.jpg` 的可疑文件。
- 可疑 ProgramData / Program Files / Public 目录落点。

### 可疑外联

排查时发现多个可疑进程存在外联或代理相关连接行为，包括：

- `47.242.194.202:7092`
- `27.124.34.221:8160`
- 本机代理端口 `127.0.0.1:7897` 被可疑进程使用过

这些地址只作为本次事件中的观测指标记录，不单独构成归因结论。

## 已完成的处置

已完成的本机处置包括：

- 终止和隔离可疑进程与文件。
- 删除伪装计划任务。
- 删除伪装 HKLM Run 启动项。
- 删除异常服务项。
- 隔离异常 WDAC / Code Integrity 策略文件。
- 清空 Microsoft Defender 危险排除项。
- 恢复 Defender 实时防护。
- 运行 Defender 快速扫描。
- 两次重启后复核持久化与外联状态。
- 保留本地隔离目录与日志，用于后续取证或报警。

## 后续建议

后续仍建议完成以下动作：

1. 运行 Microsoft Defender 脱机扫描。
2. 使用手机或确认干净的设备修改关键账号密码，包括微信、邮箱、浏览器同步账号、Steam、支付类账号等。
3. 给关键账号开启或重置多因素认证。
4. 检查微信、邮箱、浏览器、GitHub 等账号的登录设备和授权应用。
5. 保留隔离目录、日志、聊天记录、可疑 IP 和检测名称，不要打开隔离样本。
6. 如果再次出现鼠标被控制、异常弹窗、未知进程外联或安全软件被关闭，应立即断网并考虑重装系统或做专业取证。
